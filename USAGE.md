# Usage Guide

## Activation
When running `ahh.py` for the first time, you must complete the activation process:

1. **YouTube Subscription:** Select option `[1]` to open the channel URL and subscribe.
2. **WhatsApp Group:** Select option `[2]` to join the provided WhatsApp group.
3. **Approval:** Once tasks are marked as complete, select `[4]` to enter an approved key.

## Cloning Accounts
After successful activation, follow these steps:

1. Select **"OLD CLONE"** from the main menu.
2. Choose the desired series (e.g., "ALL SERIES", "100003/4 SERIES", or "2009 series").
3. Enter the total number of IDs to attempt.
4. Select the cloning method (A or B).
5. The script will output successes to the terminal and save them to `/sdcard/` (e.g., `/sdcard/AHB-OLD-M1-OK.txt`).

**Note:** The script recommends using "Airplane Mode" occasionally to improve results.
