# AHB

A tool for brute-forcing/cloning old Facebook accounts based on UIDs.

## ⚠️ Disclaimer
This tool is for educational purposes only. Unauthorized use of this tool against systems you do not own or have explicit permission to test is illegal and unethical. Use at your own risk.

## Features
- **Account Cloning:** Automates login attempts on old Facebook account series (UID-based).
- **Security Checks:** Includes basic anti-tampering and debugging detection.
- **Multiple Methods:** Supports different login strategies for better success rates.
- **User-Agent Randomization:** Randomizes Windows User-Agents for requests.

## Setup & Requirements
- Python 3
- Dependencies: `requests`, `chardet`, `urllib3`, `idna`, `certifi`, `httpx`, `bs4`, `mechanize`, `rich`.
  - *The script automatically attempts to install missing dependencies.*

## How to Use
1. Run the script:
   ```bash
   python3 ahh.py
   ```
2. Complete the activation tasks:
   - Subscribe to the YouTube channel.
   - Join the WhatsApp group.
   - Enter the required Approval Key.
3. Select the desired cloning option from the menu.
